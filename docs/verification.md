A `pass` row gives the date of the check and the evidence for it. A `not verified` row has no live result yet, and its Evidence cell says what is needed.

Rows 2, 3 and 6 were run with read-only or dry-run commands on the branch build, with HOME set to a disposable directory, and a dry run writes nothing. relaxkit ran from the branch build with PATH passed in, and OpenCode was found on PATH by `command -v opencode`. For row 3, `opencode models --standalone` was also run once as a diagnostic, outside the dry-run set, and it wrote its cache under the disposable directory. Where a row cites a test, the test runs with fixtures and does not touch a real host.
